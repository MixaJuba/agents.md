# Аналіз репозиторію AGENTS.md

## Що це за репозиторій?

**AGENTS.md** - це відкритий стандарт для керування ШІ-агентами програмування. Це простий, але потужний формат для надання інструкцій та контексту штучному інтелекту при роботі з вашими проектами.

### Основна ідея

Подумайте про AGENTS.md як про **README для агентів** - це спеціальне, передбачуване місце для надання контексту та інструкцій, які допомагають ШІ-агентам ефективно працювати з вашим проектом.

## Що дає цей репозиторій?

### 1. 🌐 Веб-сайт та документація (https://agents.md)

Репозиторій містить повноцінний веб-сайт на Next.js, який:
- Пояснює концепцію AGENTS.md простою мовою
- Показує приклади використання
- Демонструє сумісність з різними ШІ-інструментами
- Надає FAQ та інструкції з налаштування

### 2. 📚 Стандарт для індустрії

AGENTS.md використовується більш ніж **20,000+ проектів з відкритим кодом** і підтримується основними ШІ-інструментами:

**Підтримувані інструменти:**
- OpenAI Codex
- GitHub Copilot
- Cursor
- Aider
- Gemini CLI
- VS Code
- Zed
- Factory
- Devin та багато інших

### 3. 🛠️ Технічна реалізація

**Стек технологій:**
- **Next.js 15.4.4** з Turbopack
- **React 19** 
- **TypeScript** для типізації
- **Tailwind CSS 4.1.11** для стилізації
- **pnpm** як менеджер пакетів
- **Vercel Analytics** для аналітики

## Практичні кроки для початку роботи

### 1. 🔧 Налаштування середовища

```bash
# Клонувати репозиторій
git clone https://github.com/MixaJuba/agents.md.git
cd agents.md

# Встановити залежності (обов'язково pnpm!)
npm install -g pnpm
pnpm install

# Запустити dev сервер
pnpm dev
```
